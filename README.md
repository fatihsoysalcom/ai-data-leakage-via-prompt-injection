# AI data leakage via prompt injection

This Python script simulates a prompt injection vulnerability in an AI system. It demonstrates how a malicious user prompt can trick the AI into revealing sensitive internal data that it was not intended to share, even when asked to perform a legitimate task.

## Language

`python`

## How to Run

Run the script using: python main.py
